# 📱 Nombre de la Aplicación

Aplicación móvil desarrollada con **Ionic** y **Angular**, diseñada para ofrecer una interfaz moderna, intuitiva y fácil de utilizar.

Este proyecto es de **uso libre**, por lo que puedes modificarlo, adaptarlo y utilizarlo según tus necesidades.

> ⚠️ **Importante:** Para ejecutar correctamente el proyecto es necesario tener instalado **Ionic CLI**.

## 📋 Prerrequisitos

Antes de ejecutar el proyecto, asegúrate de tener instaladas las siguientes herramientas:

- **Node.js**
- **NPM**
- **Angular CLI**
- **Ionic CLI**

Si no tienes Ionic CLI instalado, puedes instalarlo ejecutando:

npm install -g @ionic/cli

🚀 Ejecución del proyecto
1. Clonar el repositorio

Clona o descarga este repositorio en tu computadora.

git clone URL_DEL_REPOSITORIO

Luego, ingresa a la carpeta del proyecto:

cd NOMBRE_DEL_PROYECTO
2. Instalar las dependencias

Ejecuta:

npm install
3. Iniciar la aplicación

Ejecuta:

ionic serve

La aplicación se abrirá en el navegador mediante el servidor de desarrollo de Ionic.
